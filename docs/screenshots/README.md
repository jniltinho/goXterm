# Screenshots

Screens of the Go app with its original icon set and fictional lab sessions, captured on Linux by
`make prints` (Xvfb, 1280×800 window) and cropped to the window. Click an image for full size; every
screen in both skins is regenerated as described in
[DEVELOPMENT.md](../DEVELOPMENT.md#screenshots-prints-and-benchmark). Screenshots of the archived Rust
app are in [`archive/rust/docs/screenshots/`](../../archive/rust/docs/screenshots/README.md).
